# CSV Extract Helpers

Column statistics and row rendering for small CSV extracts.

- col_stats.py computes per-column statistics; the contract is
  docs/stats_contract.md.
- export_util.py renders rows for export; scope notes are in
  docs/export_notes.md.
- Historical formatting conventions are collected in
  docs/legacy_notes.md.
- A sample extract lives in datasets/sample_rows.csv.
