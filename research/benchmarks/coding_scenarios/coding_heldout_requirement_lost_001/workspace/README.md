# Slug Utilities

Helpers for generating URL slugs from titles.

- `slug.py` — `slugify(title)` renders a URL-safe slug.
- `slug_report.py` — `describe_slug(title)` labels a slug for admin views.
- `docs/slug_contract.md` — the authoritative slug contract.
- `docs/legacy_notes.md` — older notes kept for history; may be out of date.

Run tests with `python -m unittest discover -s .`.
