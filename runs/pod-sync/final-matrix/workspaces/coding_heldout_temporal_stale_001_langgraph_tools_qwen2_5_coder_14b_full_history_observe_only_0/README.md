# Duration Utilities

Small helpers for rendering task durations in status output.

- `duration.py` — `format_duration(total_seconds)` renders a duration string.
- `duration_report.py` — `render_report(name, seconds)` labels a duration for logs.
- `docs/duration_contract.md` — the authoritative formatting contract.
- `docs/legacy_notes.md` — older notes kept for history; may be out of date.

Run tests with `python -m unittest discover -s .`.
